## Objective and boundaries
Apply the approved revision 2.2 visual direction to existing draft creation and activation. Reference Board A top-right for full-width library, strong title, opaque iron-framed groups, crimson action and card hierarchy. Preserve the current session-only active identity, immutable IDs and create/switch commands. Adventures, playable sheets, portraits, import, search, filters, menus and settings are outside this slice: do not display controls that suggest they work. No rules-derived data is introduced.

## Layout contract
Fixed borderless fullscreen 1920x1080 at 100% Windows scaling; no resize/maximize affordance. Use Grid sizing, not absolute content positioning. Title strip height 32, app title left, minimize and close right (40x32 each). Library banner height 144 below it: left app identity/PHB 2024 label and page title Character library; right persistent active name, Incomplete draft (or No character selected), Switch character. Reserve enough right width for wrapped long names; never show UUID/revision.

Main region: outer margin 24, gap 24, left column 560 and right remaining 1288 at target size. Two opaque framed panels: New character draft left; Saved characters right. Panel padding 24. Left form begins at top with persistent required label, input, feedback, Create draft and save feedback. Initialization/recovery feedback belongs beside the affected form/list, not a permanent database panel. Right heading remains fixed while the card collection scrolls vertically; horizontal scrolling is disabled. Cards wrap at approximately 320 DIP width with 16 DIP gaps, minimum height 180. At target width the right panel supports three cards per row. Card content wraps, including a 100-character name; avoid fixed-height clipping. No outer page scroll is needed at the accepted size.

Use existing central semantic tokens: Canvas #101419, opaque Surface #1B222A, SurfaceMuted #252E38, Text #F0EADF, TextSecondary #B8C1CC, Border #7D8997, Divider #3A4552, Brass #B89A60 and Accent #922F49. Body 16 Segoe UI; field label 14; helper minimum 13; Georgia bold page 28 and section 20. Inputs/buttons minimum height 40; panel radius 8, control radius 4, border 1, focus 2. Restrained brass line/corner geometry may decorate headings; meaningful boundaries retain Border contrast. Avoid decorative glyphs that resemble controls. No bitmap dependency.

Activation must not imply an implemented character sheet.

## State and validation matrix
| Trigger/state | Visible feedback | Enabled actions | Persistence / recovery |
|---|---|---|---|
| Startup/loading | Loading characters… | Only actions currently safe | No empty-success message |
| Empty | No characters | Create draft after initialization | No fabricated sample cards |
| Initialization failure | Characters could not be loaded. Retry. | Existing initialization retry | No path/schema/database wording |
| List failure | Characters could not be loaded. Retry. | Retry library | Do not present partial failure as empty success |
| Invalid name | Existing exact validation beside field | Existing guarded create behavior | Preserve input |
| Pending create | Saving draft… | Prevent duplicate submission | Preserve original captured name/ID behavior |
| Create success | Concise saved feedback naming the draft | Create and activate | Only after persistence succeeds |
| Create failure | Draft could not be saved. Try again. | Existing retry by create | Preserve name |
| Switch | Header and Active card update | Existing switch behavior | Session-only, no writes; pending create remains bound to original target |

No confirm/cancel dialog, catalog or numeric rules input applies to this slice.

## Keyboard and accessibility
Retain existing Ctrl+Shift+C shortcut and field-specific Enter handling. Logical tab order follows the table; no tab stops on ornaments/headings. Library scrolls the focused action into view. Preserve focus when active state changes; Switch character focuses an available library action and must remain useful for empty state. Announce important loading/error/save changes politely through existing live regions. Names wrap, full text stays accessible. System high-contrast brushes override decorative colors; hide ornaments if they interfere. Existing meaningful control boundaries, 2-DIP focus and textual Active indicator remain visible. Actual native keyboard/high-contrast verification is required; source review alone is not native evidence.
